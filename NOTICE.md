# Licencias, atribuciones y condiciones por artefacto

Cada componente tiene su propio régimen; **no se aplica una única licencia a todo el repositorio**.
Este documento es una lectura técnica de las condiciones publicadas, no asesoramiento jurídico.

| Artefacto | Régimen | Condiciones y notas |
|---|---|---|
| Código y documentación originales (`build_graph.py`, `audit_crtm.py`, `gtfs_ingest.py`, `build_explorer.py`, `snapshot_tools.py`, `validate.py`, `index.html`, `README.md`, `NOTICE.md`, `SNAPSHOT_PROTOCOL.md`, `CITATION.cff`, `.github/workflows/ci.yml`, pruebas en `tests/` y `research/`) | **MIT** ([LICENSE](LICENSE)) | Conservar el aviso de copyright. |
| `data/stations.geojson`, `data/connections.geojson`, `data/metadata.json` | **ODbL 1.0** (base de datos derivada de OpenStreetMap) | © colaboradores de OpenStreetMap, <https://www.openstreetmap.org/copyright>. Atribución obligatoria; si se publica una base derivada o adaptada, debe ofrecerse también bajo ODbL y mantenerse abierta. Estos archivos **no** son MIT. |
| `data/snapshots/<fecha>/` (instantáneas futuras; **aún no existe ninguna**), incluidas las respuestas crudas de Overpass en `raw/` | **ODbL 1.0** (extractos y base derivada de OpenStreetMap) | Ver [SNAPSHOT_PROTOCOL.md](SNAPSHOT_PROTOCOL.md). Cada `raw/RAW_MANIFEST.json` lleva la atribución y el aviso ODbL; `validate.py` falla si faltan. Las respuestas se guardan como JSON canónico reserializado (una adaptación, ofrecida bajo ODbL), no como los bytes del servidor. **No** pueden contener datos del CRTM. Lectura técnica, no asesoramiento jurídico. El snapshot v0.1.0 de `data/` queda congelado: la CI rechaza cualquier PR que lo modifique. |
| `data/manifest.json` | MIT | Metadatos del proyecto (hashes, versiones, fechas); no contiene datos de OSM ni de CRTM. |
| Auditoría CRTM (`data/crtm_audit.json`) | **No se distribuye** | Mezcla ids derivados de OSM (ODbL) con códigos oficiales de CRTM (licencia CRTM). Al exigir ambos regímenes «compartir igual», no se resolvió su combinación en un solo archivo, por lo que se excluye (`.gitignore`). Se crea en local con `audit_crtm.py`. |
| Datos del CRTM (consultados en tiempo de ejecución por `audit_crtm.py`; **no incluidos**) | [Licencia de datos abiertos y estáticos del CRTM](https://www.crtm.es/licencia-de-uso) | Citar al CRTM como fuente e indicar si el dato es bruto o procesado; mantener metadatos de fecha y condiciones; no distorsionar la información ni sugerir respaldo del CRTM; los datos originales deben compartirse con el mismo tipo de licencia. **Powered by CRTM**: <https://www.crtm.es/>. Este proyecto **no cuenta con respaldo, patrocinio ni certificación del CRTM**. Las cifras de la auditoría que aparecen en el README son resultados procesados. |
| GTFS de Metro de Madrid (`gtfs_ingest.py fetch` lo descarga en `data/gtfs_raw/`; **no incluido**) | [Licencia de datos abiertos y estáticos del CRTM](https://www.crtm.es/licencia-de-uso) | Datos **brutos**: no se distribuyen. Motivos: la licencia exige compartir los datos originales «bajo el mismo tipo de licencia» (expresión ambigua), y exige mantener la información «siempre actualizada» mientras que el feed publicado (versión 20250527, calendario hasta 2026-05-27, elemento modificado el 2025-05-30) está caducado. Se entrega un script de descarga y los hashes SHA-256 en el manifiesto. El script usa solo la URL pública, sin token. |
| Tiempos y frecuencias derivados (`data/gtfs_derived/ride_times.json`, `headways.json`, `match_report.json`) | **No se distribuyen** (`.gitignore`) | Datos **procesados** que unen ids derivados de OSM (ODbL) con valores derivados del CRTM: mismo criterio que `crtm_audit.json`, sin criterio jurídico que concilie ambos regímenes «compartir igual». Se crean en local con `gtfs_ingest.py build` y se verifican con `validate.py` contra los hashes del manifiesto. |
| `data/gtfs_derived/gtfs_manifest.json` | MIT (solo metadatos) | Hashes, versiones, parámetros supuestos y agregados (recuentos). No contiene filas del CRTM ni ids de estaciones. Cita al CRTM como fuente (datos procesados), «Powered by CRTM» y sin respaldo del CRTM. Los tiempos son **planificados** (longitud ÷ velocidad por línea, según se verificó), no medidos; la Línea 3 no está en el feed y se imputa con la misma regla desde la capa ArcGIS del CRTM (marcada como supuesto). |
| `data/explorer/disruption_topology.json` | **ODbL 1.0** (base de datos derivada de OpenStreetMap) | Resultado de simular el cierre de una estación o la desactivación de una correspondencia **solo sobre la topología** (saltos entre estaciones) del snapshot v0.1.0. No contiene datos ni valores del CRTM, ni tiempos. © colaboradores de OpenStreetMap; se ofrece bajo ODbL. Se regenera con `build_explorer.py` y `validate.py` comprueba que coincide con v0.4. |
| `research/time_weighted_v05/local/explorer_time.json` (capa de tiempos de `index.html`) | **No se distribuye** (`.gitignore`) | Une ids derivados de OSM con tiempos planificados derivados del CRTM: mismo criterio y mismos motivos que los tiempos derivados de arriba. Decisión del propietario del repositorio (2026-11-21): los tiempos solo se calculan y se ven en local. `index.html` carga el archivo si existe; si no, la capa de tiempos queda desactivada y la página funciona solo con la topología. Se crea con `python build_explorer.py --time`. |
| City2Graph 1.1.0 (dependencia instalada con pip, no redistribuida) | BSD-3-Clause (verificado en los metadatos del paquete instalado) | Ver referencia académica abajo. |
| NetworkX, GeoPandas, Shapely, pandas | BSD-3-Clause (metadatos de los paquetes instalados) | No redistribuidos. |
| DuckDB | MIT (clasificador del paquete instalado) | No redistribuido. |
| certifi | MPL-2.0 (metadatos del paquete instalado) | No redistribuido; solo aporta el bundle de certificados. |
| Leaflet 1.9.4 | BSD-2-Clause (LICENSE de la versión 1.9.4) | Cargado desde unpkg con SRI; no se redistribuye. |
| Teselas del mapa base | Teselas estándar de OpenStreetMap, [política de uso](https://operations.osmfoundation.org/policies/tiles/) | Atribución visible en el mapa; URL `https://tile.openstreetmap.org/{z}/{x}/{y}.png`; sin prefetch, descarga masiva ni uso sin conexión; servicio «best-effort» sin SLA y bloqueable sin aviso en caso de uso excesivo. Quien reutilice la página debe cumplir esa política. |
